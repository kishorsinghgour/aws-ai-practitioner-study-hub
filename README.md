## What this resource provides

The study hub supports three ways of learning:

- **Learn:** plain-language explanations, analogies, worked examples, and no-spend exercises for new learners.
- **Understand:** architecture flows, AWS service boundaries, design trade-offs, and scenario reasoning for intermediate learners.
- **Revise:** comparison tables, common traps, exam tips, service maps, and concise summaries for final review.

Each chapter includes learning objectives, detailed readings, worked scenarios, common misconceptions, practice questions, quick revision, and links to free official references.

## Recommended study approach

1. Read each chapter in order if AI and ML are new to you.
2. Complete the chapter questions without notes.
3. Review every wrong or guessed answer.
4. Use domain drills to address weak areas.
5. Complete several fresh timed simulations.
6. Aim for consistent understanding rather than memorizing answer positions.
7. Compare your coverage with every task statement in the official exam guide.
